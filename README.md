🚀 GitHub Issue Tracker
📌 Description

GitHub Issue Tracker is a simple and interactive web application where users can manage issues efficiently. It includes a login system, dynamic issue handling, and categorized tabs for better organization.

🛠️ Technologies Used
HTML
Tailwind CSS
CSS
JavaScript (DOM API, JSON)
✨ Features
🔐 Login system with username and password
📊 Issue counter with categorized tabs (All, Open, Closed)
⚡ Dynamic issue cards and modal using JavaScript

💡 This project helped me practice DOM manipulation, dynamic rendering, and building responsive UI with modern frontend tools.
